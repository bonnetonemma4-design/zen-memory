# 🌸 Zen Memory

Un jeu de mémoire calme sur le thème du spa, créé pendant mon stage chez Relax Agency (novembre-décembre 2026).

👉 **Jouer en ligne :** https://bonnetonemma4-design.github.io/zen-memory/

## Comment jouer

1. Retourne deux cartes.
2. Si les images sont pareilles, tu gagnes la paire.
3. Trouve toutes les paires pour finir le niveau.

Moins tu fais de coups, plus tu gagnes d'étoiles ⭐. Les étoiles ouvrent les niveaux suivants et débloquent des récompenses 🏆.

- 10 niveaux
- 8 récompenses à débloquer
- Fonctionne sur ordinateur et sur téléphone

## Fabriqué avec

HTML, CSS et JavaScript, dans un seul fichier (`index.html`).
